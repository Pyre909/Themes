# Pyre Generator

`Pyre Daylight.xml` and `Pyre Night.xml` are generated by `make_themes.py`. To change a colour, edit the
script and regenerate; don't hand-edit the XML.

## Regenerate

You need Python 3 and Notepad++'s style model, `stylers.model.xml`: it lists every language and style,
and it ships with Notepad++ (next to `notepad++.exe`) or is in its source at `PowerEditor/src/`. It is
not copied here because it is GPL-licensed and this repository is MIT.

```
python make_themes.py path\to\stylers.model.xml .. Consolas
python make_palette.py "..\Pyre Palette.svg"
```

- `make_themes.py <model> <output folder> [font]` writes both themes and prints each one's contrast
  table: WCAG ratio, APCA Lc, the ratio with a 10% screen glare added (Daylight), on the selection and on
  the current line. The font goes into Default Style and Global override; leave it out to keep the
  model's. Add `--roles` to print which role every style got.
- `make_palette.py <svg>` draws the swatch image and prints the colour table of `Pyre Palette.md`.
- `lexroles.py <model>` lists every language's styles with their role, one line per language.

Regenerate after a Notepad++ update that adds languages or styles to the model.

## Where things are in make_themes.py

- `NIGHT`, `DAY`: the palettes, in OKLCH (lightness, chroma, hue).
- `roles()`: colour and bold / italic per role (Daylight keywords bold, comments italic).
- `RULES`, `COLOR_ROLE`: how a style's name, or failing that its default colour, picks its role.
- `OVERRIDE`: per-language corrections, found by checking every language on screen.
- `EXTRA_STYLES`: styles a language draws but the model leaves out (FreeBASIC block and doc comments).
- `global_styles()`: caret, selection, current line, margins, Mark styles, Smart Highlighting, search
  results, tab colours.
