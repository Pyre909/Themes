# Themes
Color Themes I generated for coding, but can be used for anything else users fancy

## Fovea Light & Fovea Dark

Notepad++ themes whose syntax colors were chosen from vision-science data rather than by eye: as little color as possible, nothing bright enough to glow, and every token type identifiable at a glance.

![Fovea palette](Fovea%20Palette.svg)

Hex values, contrast, how they compare with One Light/Dark, and install steps: [Fovea Palette.md](Fovea%20Palette.md)

## Pyre Daylight & Pyre Night

A pair of Notepad++ themes: Daylight readable with sunlight on the screen, Night for long sessions in the dark. Set Night as the Dark Mode theme and Daylight as the light one, and the Dark Mode switch changes between them.

![Pyre palette](Pyre%20Palette.svg)

Hex values, contrast, the reasoning behind each colour, and install steps: [Pyre Palette.md](Pyre%20Palette.md). The themes are generated by the scripts in [Pyre Generator](Pyre%20Generator/README.md).
